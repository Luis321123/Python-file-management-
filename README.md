## 📖 About

A **file management** service in Python that combines **FastAPI**,
**AWS** services and **Docker** (with Alembic migrations and a local
environment file) into a clean, deployable API.

## ✨ Features

- FastAPI application (`app/`)
- **AWS** service integration
- Alembic migrations + `docker-compose.yml`
- Local env config via `local.env`
